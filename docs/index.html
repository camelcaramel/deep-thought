생각해야 풀리는 실무 문제

Deep Thought는 고등학생용 실무 문제 시뮬레이터입니다. 티켓을 받아 코드를 고치고, 운영에 배포하고, 그 결과에 대응합니다. 모두 내 PC에서 합니다.

가상 시각

09:00

이 페이지를 연 때를 9시로 하고 실제 1초에 가상 5분씩 흐르는 시계입니다.

이 페이지를 연 때가 09:00 · 실제 1초가 5분

운영 배포 한 번에 하루치 요청이 흐릅니다. 실제로는 약 5분입니다.

AI를 마음껏 쓰세요. 판단은 직접 합니다.

AI에 제한이 없습니다
평소 쓰는 AI 코딩 도구를 그대로 쓰세요. 무엇을 시켰고 무엇을 받아들였는지는 보고서에 남깁니다.
정답보다 근거를 봅니다
맞혔는지보다 무엇을 보고 그렇게 판단했는지가 중요합니다. 근거는 로그, 동료의 답, 실행 결과입니다.
운영 배포는 되돌릴 수 없습니다
로컬 확인은 몇 번이든 할 수 있지만 운영 배포는 한 단계에 한 번입니다. 언제 누를지 스스로 정합니다.
고치지 않고 답할 수 있습니다
모든 문제에 “수정하지 않고 답하기”가 있습니다. 고치지 않기로 했다면 그 이유를 요청자에게 적어 보냅니다.

문제 하나는 이렇게 진행됩니다

문제 하나에 수업 2시간 정도 걸립니다. 보고서는 3일 안에 냅니다.

  1. 01 / 05티켓
  2. 02 / 05수정 · 로컬 확인
  3. 03 / 05운영 배포
  4. 04 / 05결과에 대응
  5. 05 / 05보고서

티켓을 읽습니다

회사에서 일을 받듯 티켓을 받습니다. 누가 무엇을 왜 바라는지 읽고, 무엇을 확인할지 정하세요.

고치고 로컬에서 확인합니다

평소 쓰는 편집기와 AI 도구로 코드 폴더를 고칩니다. 로컬 확인은 약 1분 걸리고 횟수 제한이 없습니다.

운영에 배포합니다

누구에게 어떤 영향을 줄지 먼저 적고 시작합니다. 하루치 요청이 약 5분 동안 흐릅니다. 빌드가 실패하면 횟수는 줄지 않습니다.

장애가 나면 화면이 뒤집힙니다

화면 색이 운영 상태입니다. 문제가 없으면 밝은 화면 그대로이고, 장애가 나면 화면 전체가 검어집니다. 알림에는 겉으로 드러난 증상만 있습니다. 원인은 직접 찾습니다.

로그
운영 로그를 검색하고 필요한 줄을 CSV로 내려받습니다.
질문
동료에게 Discord로 묻습니다. 선생님이 동료 역할로 답합니다.
복구 배포
고친 코드를 한 번 더 운영에 배포합니다. 이것도 한 번입니다.

보고서를 씁니다

프로그램이 적은 기록을 내려받아 보고서를 씁니다. 장애를 냈더라도 과정을 솔직하고 구체적으로 돌아보면 좋은 보고서입니다.

설치

서명하지 않은 실험용 프로그램이라 처음 열 때 보안 경고가 나옵니다. 아래 순서대로 여세요.

Windows 10 · 11
  1. IncidentSim-windows.exe를 내려받으세요. 브라우저가 막으면 내려받기 목록에서 유지를 고르세요.
  2. 받은 파일을 두 번 눌러 실행하세요.
  3. “Windows의 PC 보호” 창이 나오면 추가 정보를 누르고 실행을 누르세요.
  4. 설치가 끝나면 나머지 파일을 내려받습니다. 다 받으면 프로그램 창이 열립니다.
  5. 다음부터는 시작 메뉴의 바로 가기로 여세요.
macOS
  1. IncidentSim-macos.zip을 내려받아 압축을 푸세요. Safari는 저절로 풉니다.
  2. IncidentSim 앱을 응용 프로그램 폴더로 옮기고 두 번 눌러 여세요.
  3. 열 수 없다는 경고가 나오면 완료를 누르세요. 휴지통으로 옮기지 마세요.
  4. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래쪽에서 그래도 열기를 누르세요. 다시 묻는 창에서도 여세요.
  5. 나머지 파일을 다 받으면 프로그램 창이 열립니다. 다음부터는 경고 없이 열립니다.
Ubuntu 64비트
  1. IncidentSim-ubuntu.deb를 내려받으세요.
  2. 터미널에서 받은 폴더로 가세요. 한국어 환경은 cd ~/다운로드, 영어 환경은 cd ~/Downloads입니다.
  3. sudo apt install ./IncidentSim-ubuntu.deb로 설치하세요.
  4. 앱 목록에서 Deep Thought를 여세요. 나머지 파일을 다 받으면 창이 열립니다.

설명서 전체 읽기

자주 묻는 것

AI를 정말 마음껏 써도 됩니까

네. 도구도 횟수도 제한하지 않습니다. 다만 AI 도구에는 코드 폴더만 열어 주고, 나눈 대화는 지우지 말고 보고서에 붙이세요.

Java를 설치해야 합니까

아니요. 이 PC에 JDK 21이 없으면 프로그램이 자기 폴더 안에 내려받아 씁니다.

진짜 서버에 배포됩니까

아니요. 운영 서버도, 그곳에 오는 요청도 모두 내 PC 안에서 돕니다.

인터넷 없이 쓸 수 있습니까

처음 켤 때, 문제의 첫 빌드 때, Discord로 질문할 때는 인터넷이 필요합니다. 필요한 파일을 모두 받은 뒤에는 인터넷이 없어도 켜집니다.

질문에는 누가 답합니까

선생님이 동료 역할로 Discord에서 답합니다. 프로그램은 질문을 복사하고 Discord를 열기만 합니다. 저절로 보내는 것은 없습니다.

운영 배포를 실수로 누르면 어떻게 됩니까

영향 분석 메모를 쓰고 확인 칸을 채운 뒤 시작 버튼을 눌러야 배포가 시작됩니다. 그 전에는 취소할 수 있습니다. 시작하면 되돌릴 수 없습니다.

창이 열리지 않습니다

브라우저에서 http://127.0.0.1:17300/을 여세요. 그래도 안 되면 프로그램 아이콘을 다시 누르세요. 진행 상황은 그대로 남아 있습니다.

지우려면 어떻게 합니까

먼저 프로그램 안의 “데이터 모두 지우기”로 기록과 코드 폴더를 지우고, 그다음 프로그램을 제거하세요. 운영 체제별 제거 방법은 설명서에 있습니다.

테스터 약속

  • AI 도구에는 코드 폴더만 열어 줍니다.
  • 프로그램을 뜯어보거나, 기록을 지우고 운영 배포를 다시 하지 않습니다.
  • 실험이 끝날 때까지 다른 테스터에게 답이나 단서를 알려 주지 않습니다.
  • AI와 나눈 대화는 지우지 않고 보고서에 붙입니다.

약속을 어긴 것을 솔직하게 적어 내는 것은 감점하지 않습니다.
